# QA Automation Project

Projeto de automação de testes desenvolvido utilizando **Python**, **Selenium WebDriver** e o padrão **Page Object Model (POM)** para validar funcionalidades do **SauceDemo**.

## Objetivo

O principal objetivo deste projeto é demonstrar conhecimentos em:

- Automação de testes Web
- Selenium WebDriver
- Python
- Page Object Model (POM)
- Estruturação de projetos de automação
- Geração de logs
- Manutenção e reutilização de código

---

## Tecnologias Utilizadas

- Python 3.x
- Selenium WebDriver
- ChromeDriver
- Pytest
- Logging
- Page Object Model (POM)

---

## Funcionalidades Automatizadas

Atualmente o projeto contempla automações para:

- Login
- Cadastro de usuário
- Acesso à conta
- Navegação entre páginas
- Validação de elementos
- Tratamento de erros
- Registro de logs das execuções

---

## Como executar

### Clone o repositório

```bash
git clone https://github.com/lucashernandez90/qa-automation-project.git
```

Entre na pasta

```bash
cd qa-automation-project
```

Instale as dependências

```bash
pip install -r requirements.txt
```

Execute o projeto

```bash
python main.py
```
